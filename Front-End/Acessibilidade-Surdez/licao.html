Títulos e parágrafos em HTML

O que você vai aprender

Todo texto de uma página precisa de estrutura. O HTML usa tags para dizer o que cada trecho é: um título, um parágrafo, uma lista.

A tag <h1> marca o título principal. A tag <p> marca um parágrafo. Usar a tag certa ajuda leitores de tela e buscadores a entender a página.

Código

<h1>Meu primeiro site</h1>
<p>Olá! Estou aprendendo HTML.</p>
<h2>Sobre mim</h2>
<p>Gosto de tecnologia e de Libras.</p>
