Box model

              

                Todo elemento é uma caixa com quatro camadas: conteúdo,
                padding (espaço interno),
                border (borda) e margin (espaço
                externo).
              

              
Exemplo de código

              
.caixa {
  padding: 1rem;            /* espaço dentro da borda */
  border: 6px solid #2b3bd6; /* borda */
  margin: 1rem;             /* espaço fora da borda */
}

              
Resultado esperado

              

                
Conteúdo da caixa

              

            

            

              
Cores e contraste

              

                Defina cor do texto e do fundo. O contraste entre as duas
                precisa ser alto: mínimo de 4,5 para 1 em texto comum (WCAG).
              

              
Exemplo de código

              
.bom  { color: #16193b; background: #ffd23f; } /* contraste alto */
.ruim { color: #aaaaaa; background: #ffffff; } /* difícil de ler */

              
Resultado esperado

              

                

                  Bom contraste
                  Mau contraste
                

              

            

            

              
Tipografia

              

                Texto legível usa fonte clara, tamanho em rem,
                espaço entre linhas e linhas curtas.
              

              
Exemplo de código

              
body {
  font-family: "Atkinson Hyperlegible", sans-serif; /* fonte fácil de ler */
  font-size: 1.125rem;  /* 18px */
  line-height: 1.7;     /* espaço entre linhas */
}
p { max-width: 70ch; }  /* linhas não muito longas */

              
Resultado esperado

              

                

                  Linhas curtas e bom espaço entre elas deixam a leitura mais
                  confortável.
                

              

            

            

              
Layout e posição

              

                display define como o elemento se comporta.
                position controla onde ele fica na tela.
              

              
Exemplo de código

              
.cabecalho {
  position: sticky; /* gruda no topo ao rolar */
  top: 0;
}
.menu { display: flex; } /* itens lado a lado */
.escondido { display: none; } /* some da tela */

              
Resultado esperado

              

                

                  O cabeçalho do Dev Acess usa position: sticky:
                  ele continua visível no topo enquanto você rola a página.
                

              

            

            

              
Flexbox

              

                Flexbox organiza itens em uma linha ou coluna e divide o espaço
                entre eles.
              

              
Exemplo de código

              
.linha {
  display: flex;  /* ativa o flexbox */
  gap: .5rem;     /* espaço entre itens */
  justify-content: space-between; /* distribui na linha */
}

              
Resultado esperado

              

                

                  123
                

              

            

            

              
Grid

              

                Grid organiza itens em linhas e colunas ao mesmo tempo.
              

              
Exemplo de código

              
.grade {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 colunas iguais */
  gap: .5rem;
}

              
Resultado esperado

              

                

                  123456
                

              

            

            

              
Responsividade

              

                Uma página responsiva se adapta a celular, tablet e computador.
                Use medidas flexíveis e @media.
              

              
Exemplo de código

              
/* Colunas que se ajustam sozinhas à largura da tela */
.grade { display: grid;
  grid-template-columns: repeat(auto-fit, minmax(6rem, 1fr)); }

/* A partir de 60rem de largura, muda o layout */
@media (min-width: 60rem) {
  .lateral { display: block; }
}

              
Resultado esperado

              

                

                  ABCDE
                

                
Diminua a janela: os blocos mudam de linha.

              

            

            

              
Animações

              

                Animações chamam atenção, mas podem incomodar. Respeite quem
                pediu menos movimento com prefers-reduced-motion.
              

              
Exemplo de código

              
@keyframes mover { to { transform: translateX(10rem); } }
.bolinha { animation: mover 2s ease-in-out infinite alternate; }

@media (prefers-reduced-motion: reduce) {
  .bolinha { animation: none; } /* sem movimento */
}

              
Resultado esperado

              

                

                

                  O quadrado se move. Com “Reduzir animações” ativado, ele fica
                  parado.

Glossário

              

                
Seletor

                

                  Parte do CSS que escolhe quais elementos recebem o estilo.
                

                
Propriedade e valor

                

                  Em color: red, color é a propriedade
                  e red é o valor.
                

                
Box model

                
Modelo de caixa: conteúdo, padding, borda e margin.

                
rem

                

                  Unidade de medida baseada no tamanho da fonte da página. 1rem
                  costuma ser 16px.
                

                
Pseudo-classe

                

                  Estado do elemento, como :hover (mouse em cima) e
                  :focus (teclado).
                

                
Media query

                

                  Regra @media que só vale em certas condições,
                  como largura da tela.
                

                
Contraste

                

                  Diferença de brilho entre texto e fundo. Quanto maior, mais
                  fácil de ler.
                

                
Viewport

                
Área visível da página no navegador.
