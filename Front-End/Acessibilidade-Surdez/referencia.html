Guia de referência de HTML

HTML é a linguagem que dá estrutura às páginas. Aqui estão os assuntos principais, em linguagem simples, com código comentado.

Estrutura da página

Toda página HTML tem a mesma base: o tipo do documento, o idioma, a cabeça (head) com informações e o corpo (body) com o que aparece na tela.

Exemplo de código

<!DOCTYPE html>  <!-- avisa o navegador: é HTML5 -->
<html lang="pt-BR">  <!-- idioma da página: ajuda leitores de tela -->
<head>
  <meta charset="utf-8">  <!-- permite acentos -->
  <title>Minha página</title>  <!-- nome que aparece na aba -->
</head>
<body>
  <h1>Olá, mundo!</h1>  <!-- o que aparece na tela -->
</body>
</html>

Resultado esperado

Olá, mundo!

A aba do navegador mostra o nome “Minha página”.

Semântica

Tags semânticas dizem o que cada parte da página é. Isso ajuda leitores de tela, buscadores e quem edita o código.

Exemplo de código

<header>Topo: logo e título</header>
<nav>Menu de navegação</nav>
<main>
  <article>Conteúdo principal</article>
</main>
<footer>Rodapé</footer>

Resultado esperado

header — topo
nav — menu
main — article — conteúdo principal
footer — rodapé

Formulários

Formulários coletam dados. Todo campo precisa de um label ligado a ele, para que todos saibam o que preencher.

Exemplo de código

<form>
  <label for="nome">Seu nome</label>  <!-- "for" liga ao id do campo -->
  <input id="nome" name="nome" type="text" required>
  <button type="submit">Enviar</button>
</form>

Resultado esperado


Imagens

A tag img mostra imagens. O atributo alt descreve a imagem em texto, para quem não a vê.

Exemplo de código

<img src="circulo.svg"
     alt="Círculo azul-escuro sobre fundo amarelo"
     width="160" height="90">
<!-- Imagem só decorativa? Use alt="" -->

Resultado esperado

Links

O link leva a outra página ou parte da página. O texto do link deve fazer sentido sozinho: evite “clique aqui”.

Exemplo de código

<a href="referencia-css.html">Ir para o guia de CSS</a>
<!-- href="#glossario" leva a um trecho da mesma página -->

Resultado esperado

Ir para o glossário desta página

Tabelas

Use tabelas só para dados. caption dá o título e th marca os cabeçalhos.

Exemplo de código

<table>
  <caption>Trilhas do Dev Acess</caption>
  <tr><th scope="col">Trilha</th><th scope="col">Serve para</th></tr>
  <tr><td>HTML</td><td>Estrutura</td></tr>
  <tr><td>CSS</td><td>Aparência</td></tr>
</table>

Vídeo e áudio

As tags video e audio tocam mídia. Para pessoas surdas, a legenda (track) é essencial.

Exemplo de código

<video controls>
  <source src="aula.mp4" type="video/mp4">
  <!-- legenda em português -->
  <track kind="captions" src="aula.vtt" srclang="pt-BR" label="Português" default>
</video>

Resultado esperado

Aparece um player com botões de play, volume e tela cheia. Ao ativar a legenda, o texto do que é falado surge sobre o vídeo.

Acessibilidade

Acessibilidade é fazer a página funcionar para todos. Para pessoas surdas: legendas, transcrição, Libras e não depender só de som.

Exemplo de código

<html lang="pt-BR">                 <!-- idioma declarado -->
<a href="#conteudo">Pular para o conteúdo</a>  <!-- ajuda no teclado -->
<img src="grafico.png" alt="Gráfico de vendas em alta">
<video controls>...</video>
<details><summary>Transcrição</summary>...</details>

Resultado esperado

  • Todo vídeo tem legenda e transcrição.
  • Toda imagem tem texto alternativo.
  • Tudo funciona só com o teclado.
  • Um alerta nunca usa só som ou só cor.

Glossário

Tag
Marca escrita entre < e >, como <p>.
Elemento
A tag de abertura, o conteúdo e a tag de fechamento juntos.
Atributo
Informação extra dentro da tag, como alt ou href.
Semântica
O significado de cada tag: “isto é um menu”, “isto é um rodapé”.
Leitor de tela
Programa que lê a página em voz alta ou em Braille. Usado por pessoas cegas.
Texto alternativo
Descrição em texto de uma imagem (atributo alt).
Legenda
Texto sincronizado com o vídeo, que mostra o que é falado e os sons importantes.
Transcrição
Versão completa em texto de um vídeo ou áudio.
