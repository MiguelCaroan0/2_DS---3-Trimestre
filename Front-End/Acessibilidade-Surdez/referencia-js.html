Guia de referência de JavaScript

JavaScript faz a página reagir: calcula, escuta cliques e busca dados. Os assuntos abaixo seguem uma ordem boa de estudo.

Variáveis

Variável é uma “caixa” com nome que guarda um valor. Use const para valores fixos e let para valores que mudam.

Exemplo de código

const nome = "Ana"; // const: o valor não muda
let idade = 20;     // let: o valor pode mudar
idade = 21;         // mudamos o valor
console.log(nome, idade); // mostra no console

Resultado esperado

No console aparece: Ana 21

Tipos de dados

Os valores têm tipos: texto (string), número, verdadeiro/falso (boolean), vazio (null) e não definido (undefined).

Exemplo de código

typeof "oi"   // "string"  → texto
typeof 42     // "number"  → número
typeof true   // "boolean" → verdadeiro ou falso
typeof undefined // "undefined" → sem valor ainda

Resultado esperado

O console mostra o tipo de cada valor, como number para 42.

Funções

Função é um bloco de código com nome que você pode usar várias vezes.

Exemplo de código

function dobro(numero) { // numero é o parâmetro
  return numero * 2;     // devolve o resultado
}
console.log(dobro(5));   // chama a função

Resultado esperado

No console aparece: 10

Condicionais

Condicionais fazem o código escolher um caminho: se algo é verdade, faz uma coisa; senão, faz outra.

Exemplo de código

const nota = 7;
if (nota >= 6) {
  console.log("Aprovada");   // roda se for verdade
} else {
  console.log("Em recuperação"); // roda se for falso
}

Resultado esperado

No console aparece: Aprovada

Loops

Loops repetem um trecho de código sem você escrever várias vezes.

Exemplo de código

for (let i = 1; i <= 3; i++) { // começa em 1, vai até 3
  console.log("Volta " + i);
}

Resultado esperado

No console aparece: Volta 1, Volta 2 e Volta 3.

Arrays

Array é uma lista ordenada de valores. A contagem de posições começa em zero.

Exemplo de código

const frutas = ["maçã", "uva"];
frutas.push("pera");            // adiciona no fim
console.log(frutas[0]);         // primeiro item: "maçã"
const grandes = frutas.filter(f => f.length > 3); // filtra

Resultado esperado

No console aparece: maçã. A lista grandes fica com ["maçã", "pera"].

Objetos

Objeto agrupa informações relacionadas em pares de nome e valor.

Exemplo de código

const aluno = {
  nome: "Ana",
  curso: "HTML"
};
console.log(aluno.nome); // acessa com ponto
aluno.curso = "CSS";     // muda o valor

Resultado esperado

No console aparece: Ana

DOM

O DOM é a página vista pelo JavaScript. Com ele você encontra elementos e muda seu conteúdo.

Exemplo de código

const texto = document.querySelector("#demo-dom-texto"); // encontra
texto.textContent = "Texto mudado pelo JavaScript!";     // muda

Resultado esperado

Texto original.

Eventos

Evento é algo que acontece na página: um clique, uma tecla, um envio. O código “escuta” o evento e reage.

Exemplo de código

const botao = document.querySelector("#demo-cont-btn");
let cliques = 0;
botao.addEventListener("click", () => { // escuta o clique
  cliques++;
  console.log("Cliques: " + cliques);
});

Resultado esperado

Nenhum clique ainda.

Fetch (buscar dados)

fetch pede dados a outro site (uma API). Como demora, usamos async e await para esperar a resposta.

Exemplo de código

async function buscarCep(cep) {
  const resposta = await fetch(`https://viacep.com.br/ws/${cep}/json/`);
  const dados = await resposta.json(); // vira objeto
  console.log(dados.logradouro);
}
buscarCep("01001000");

Resultado esperado


Tratamento de erros

Erros acontecem. try/catch tenta rodar o código e, se falhar, mostra uma mensagem clara em vez de quebrar a página.

Exemplo de código

try {
  JSON.parse("{texto sem aspas}"); // isto vai falhar
} catch (erro) {
  console.log("Erro capturado: " + erro.message);
}

Resultado esperado

Glossário

Variável
Nome que guarda um valor na memória.
Função
Bloco de código reutilizável, que pode receber valores e devolver um resultado.
Array
Lista ordenada de valores.
Objeto
Grupo de informações com nome e valor.
DOM
Representação da página que o JavaScript consegue ler e alterar.
Evento
Algo que acontece na página, como clicar ou digitar.
API
Serviço que entrega dados para outros programas.
Assíncrono
Que acontece em segundo plano, sem travar a página (como o fetch).
Console
Área do navegador onde aparecem mensagens e erros do código.
